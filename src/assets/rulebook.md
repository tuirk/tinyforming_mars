TINYforming Mars - Complete Rulebook
Game Overview
TINYforming Mars is a strategy game for 2 players where you compete to terraform Mars by managing three Parameters: Heat, Greenery, and Water. Players use Project cards and Standard Projects to place parameter tiles on the map, build cities, and score victory points. The game ends when 2 of the 3 parameter types are exhausted from supply or when no unoccupied hexes remain on the map.
Components

2 Mars maps (THARSIS and ELYSIUM) - 19 hexes each
7 double-sided Project cards (14 project options total)
Parameter Tiles: Red (Heat), Green (Greenery), Blue (Water)
4 Resource Tokens: Nature x2, Production x1, Science x1
City Tokens: White and Black
Player Tokens: Blank tokens for tracking usage
Credits

The Five Tag Types

Energy Production (Purple lightning bolt)
Production (Orange factory)
Nature (Green leaves)
Science (White lightbulb)
Space (Gray rocket)

Map Layout
Each Mars map contains 19 hexes:

5 Water Hexes: Light blue background, reserved for Water Tiles only
14 Land Hexes: Can hold Cities or Greenery Tiles
5-7 Bonus Hexes: Thick colored borders provide tag bonuses to cities placed on them
Resource Token Hexes: Some water hexes have resource token icons

THARSIS Map

Row 1: Production tag (orange frame), empty, Science tag (blue hex)
Row 2: All brown hexes (empty)
Row 3: Nature tag (green frame), Nature tag (blue hex), Nature tag (blue hex), empty, Nature tag (green frame)
Row 4: Empty, empty, Nature tag (blue hex), empty blue hex
Row 5: Production tag (orange frame), empty, Space tag (gray frame)

ELYSIUM Map

Row 1: Science tag (blue hex), Production tag (blue hex), empty
Row 2: Space tag (gray hex), empty, empty blue hex, Science tag (white hex)
Row 3: Empty, Nature tag (blue hex), Nature tag (brown hex), Nature tag (blue hex), empty
Row 4: Empty, Production tag, empty, Production tag, empty
Row 5: Production tag, empty, Production tag

Game Setup
Steps 1-6: Basic Setup

Choose and place one Mars map (THARSIS or ELYSIUM) in the center
Create Parameter Tile supply piles: Red (Heat), Green (Greenery), Blue (Water)
Create Resource Token supply: 2 Nature, 1 Production, 1 Science tokens
Shuffle the 7 double-sided Project cards, place as draw deck with discard space
Each player takes their City Tokens and blank Player Tokens
Players receive starting Credits

Steps 7-9: Initial Project Card Deal

White player draws first Project card, flips face-up, decides which side faces them vs Black player
Black player draws second Project card, flips face-up, decides which side faces them vs White player
White player draws third Project card, flips face-up, decides which side faces them vs Black player

Result: Each player has 3 project effects facing them and gains their automatic tags immediately.
Steps 10-11: Starting City Placement

Black player places one City Token on any hex not reserved for water
White player places one City Token on any hex not reserved for water AND not adjacent to Black player's city

Standard Projects
Once per Generation, each player may complete one of the five Standard Projects if requirements are met. Place your blank Player Token on the Standard Project as a reminder.
1. Sell Patent

Cost: Free
Requirements: Credits must be available in supply
Effect: Gain 1 Credit

2. Build City

Cost: 2 Credits + 1 Energy Production tag + 1 Space tag
Effect: Place or relocate one City Token
Rules: Max 2 cities per player, no adjacency to other cities, not on water hexes

3. Import Water

Cost: 3 Credits + 1 Science tag
Effect: Place 1 Water Tile on unoccupied water hex
Bonuses: Gain resource token if hex has icon; gain 1 Credit per adjacent Water Tile

4. Greenhouses

Cost: 3 Credits + 2 Nature tags
Effect: Place 1 Greenery Tile on unoccupied land hex

5. Energy Farms

Cost: 3 Credits + 1 Energy Production tag + 1 Science tag
Effect: Gain 1 Heat Tile to personal supply

Project Cards
Each Project card is double-sided with two project effects per side (4 total effects per card). During setup and Research Phases, one side is chosen, giving each player one project from that side.
Project Card Components

Project Name
Cost: Credits required (asterisk * indicates cost can be reduced)
Tag Requirements: Required tags to activate
Parameter Requirements: Required parameter tiles on map/in supply
Effect: What the project does when activated
Automatic Tags: Tags provided immediately when card faces you

Project Card Rules

Each project can only be activated once per Generation
Mark usage by placing 1 Credit on the project card
Must meet ALL requirements (credits, tags, parameters) to activate
Automatic tags are available immediately, even without activating the project
Project text supersedes rulebook when conflicts arise

Resource Tokens

Acquisition: Gained when placing Water Tiles on hexes with resource icons, or from certain project effects
Usage: Spend (return to supply) to gain 1 matching tag for meeting requirements
Types: Nature (2 available), Production (1), Science (1)

Parameters
Heat Tiles (Red)

Personal Supply: When gained, goes to your personal collection
Map Placement: Some projects place Heat directly on map
Victory Points: +1 VP per Heat in personal supply, -1 VP per Heat on map adjacent to your cities

Greenery Tiles (Green)

Map Placement: Always placed on land hexes (not water-reserved)
Victory Points: Each Greenery adjacent to your cities = +1 VP (+1 additional if adjacent only to your cities)

Water Tiles (Blue)

Map Placement: Only on water-reserved hexes (light blue background)
Effects: Resource tokens if hex has icon, credits for adjacent water tiles
Income: +1 Credit per Generation to each adjacent city
Victory Points: +1 VP if adjacent only to your cities

Generations (Gameplay)
Turn Order: White player starts odd Generations (1,3,5...), Black player starts even Generations (2,4,6...)
Each Generation has three phases in order:
1. Research Phase
Generation 1: Skip (cards already dealt in setup)
Generation 2+:

Starting player draws card 1, flips, chooses sides
Other player draws card 2, flips, chooses sides
Starting player draws card 3, flips, chooses sides
Each player now has 3 new projects facing them

2. Action Phase
Players alternate taking one action until both pass:

Complete a Project card (if requirements met)
Complete a Standard Project (if requirements met)
Pass (cannot take more actions this phase)

Restrictions:

Each Project card can only be used once per Generation
Each player can only use 1 Standard Project per Generation
Credits on Project cards cannot be removed during Action Phase

Phase End: When both players pass, return all credits on Project cards to supply, discard Project cards, reshuffle discard pile if needed.
3. Income Phase
In turn order:

Collect 1 Credit per city owned
Collect 1 Credit per Water Tile adjacent to each city
Credit Limit: Keep maximum 5 Credits, return excess to supply

End Game Check:

Game continues if fewer than 2 parameter types exhausted AND at least 1 unoccupied hex remains
Game ends if 2+ parameter types exhausted OR no unoccupied hexes remain

Victory Conditions & Scoring
Victory Points

Heat Tiles: +1 VP per Heat in personal supply
Heat Penalty: -1 VP per Heat on map adjacent to your cities
Greenery Bonus: +1 VP per Greenery adjacent to your cities (+1 additional if adjacent only to your cities)
Water Bonus: +1 VP per Water Tile adjacent only to your cities
Bonus Hexes: Cities on bonus hexes provide that tag type while present

Game End
Game ends immediately when either:

2 out of 3 Parameter Tile types are exhausted from supply, OR
No unoccupied hexes remain on the map

Player with the most Victory Points wins. Tiebreaker: Most Credits remaining.
Key Strategic Concepts
Tag Management

Sources: Project cards (automatic), cities on bonus hexes, spent resource tokens
Flexibility: Resource tokens provide temporary tags when needed
Planning: Consider tag requirements when choosing project card sides

Parameter Timing

Supply Management: Game ends when 2/3 parameter types exhausted
Competitive Placement: Water and Greenery placement affects opponent scoring
Heat Strategy: Balance personal collection vs map placement penalties

City Positioning

Adjacency Rules: No cities can be adjacent to each other
Income Optimization: Position near water for income bonuses
Bonus Hexes: Strategic placement for additional tags
Greenery Synergy: Cities near greenery gain victory points

Project Card Selection

Dual Purpose: Consider both automatic tags and activation effects
Cost Reduction: Look for projects with asterisk (*) cost reduction abilities
Synergy: Choose sides that complement your strategy and deny opponent options
